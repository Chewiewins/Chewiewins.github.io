# Chewiewins.github.io
User-site root. Hosts `/.well-known/assetlinks.json` (Digital Asset Links) for the Goal Weight Calculator Android app (package `io.github.chewiewins.goalweight`).

The fingerprint list must contain the upload key AND, once the app is in Play Console, the Play App Signing key (Play Console > Setup > App signing > "App signing key certificate" SHA-256). Add it as a second entry in `sha256_cert_fingerprints`.
